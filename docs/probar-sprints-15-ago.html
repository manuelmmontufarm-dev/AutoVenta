💬 Chat de prueba de punta a punta

Un solo chat toca casi todo: medida → opciones → precio → cotización → local → fecha.

Escribe, en este orden:
1. «buenas, necesito llantas 205/55R16» → llegan las opciones con sello de medida
2. «a cómo salen?» → debe darte la recomendación de una, no preguntarte si quieres una
3. «dale, cotízame 4» → llega la cotización; revisa que el total esté con punto ($555.57, no $555,56)
4. «voy al sur» → registra Quito Sur
5. «paso el lunes» → solo pregunta el día o confirma; NO vuelve a preguntar cuál local
